# سفرية ديزرت — Safarya Desert

موقع حجز رحلات سفاري بعربيات الدفع الرباعي في الصحراء الغربية المصرية: الصحراء البيضاء والسوداء، واحة سيوة، الفيوم ووادي الحيتان، كهف جارة، الواحات الكبرى، والجلف الكبير.

**الخطوات المطلوبة منك للتشغيل الكامل في [DEPLOY.md](DEPLOY.md).**

الموقع إنجليزي أساسي (للأجانب، الأسعار بالدولار) على `/`، ونسخة عربي كاملة (الأسعار بالجنيه) على `/ar/`. المحتوى الإنجليزي في `shared/catalog-en.js`.

## الصفحات
| المسار | الصفحة |
|---|---|
| `/` | الرئيسية: شرائح صور حقيقية، الرحلات، المحميات، مقارنة الأسعار، المواسم |
| `/trips/` | كل الرحلات: بحث، فلترة بالمدة والوجهة والشهر، ترتيب |
| `/trips/<id>.html` | صفحة لكل رحلة (١٢ صفحة): معرض صور، البرنامج، الشامل، الموسم، تحقق التوافر |
| `/book/` | الحجز: تقويم بالأماكن الفاضية، حساب السعر، أطفال بفئتين عمريتين، تأكيد |
| `/booking/` | متابعة الحجز برقمه + الموبايل، شاشة النجاح، الإلغاء حسب السياسة |
| `/contact/` `/faq/` `/privacy/` `/terms/` `/credits/` | تواصل، أسئلة، خصوصية، شروط، مصادر الصور |
| `/admin/` | لوحة الإدارة (محمية بكلمة سر من السيرفر) |

## البنية
```
shared/            البيانات والأسعار — مصدر واحد للموقع والسيرفر
  catalog.js       الرحلات، المحميات، الأسئلة، السياسات
  pricing.js       حساب السعر والتواريخ وأرقام الموبايل
data/images.json   صور الأماكن (Wikimedia Commons) بالمصوّر والترخيص
assets/            CSS و JavaScript الواجهة (من غير مكتبات)
worker/            السيرفر (Cloudflare Worker + D1) + الاختبارات
tools/build.mjs    بيولّد الصفحات و sitemap و image-sources.csv
image-sources.csv  مصدر وترخيص كل صورة والصفحات اللي بتستخدمها
```

## أوامر
```bash
node tools/build.mjs                          # بناء الصفحات بعد تعديل البيانات
node --no-warnings tools/dev-server.mjs       # تجربة كاملة على localhost:8080
node --no-warnings worker/test/run.mjs        # اختبارات السيرفر
node tools/verify-images.mjs                  # إعادة التحقق من تراخيص الصور
```
