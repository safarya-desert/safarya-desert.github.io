# سفرية ديزرت — Safarya Desert

موقع حجز رحلات سفاري بعربيات الدفع الرباعي في الصحراء الغربية المصرية: الصحراء البيضاء والسوداء، واحة سيوة، الفيوم ووادي الحيتان، كهف جارة، الواحات الكبرى، والجلف الكبير.

## المحتوى
- ١٢ رحلة بأسعار للمصريين (ج.م) وللأجانب ($)، وفلاتر حسب مدة الرحلة
- صفحة تفاصيل لكل رحلة: البرنامج يوم بيوم، واللي شامله السعر
- قسم المحميات الطبيعية
- مقارنة بأسعار السوق
- حاسبة حجز مباشرة (أطفال، رحلة خاصة، ترقية إقامة، مقدم ٣٠٪) بترسل الطلب على واتساب

## التعديل
كل الإعدادات في أول `<script>` في ملف `index.html`:
- `WHATSAPP` — رقم الواتساب بالصيغة الدولية من غير `+` (مثال: `201012345678`)
- `PHOTOS` — روابط صور الأماكن؛ أي صورة بتتحط هنا بتاخد مكان الرسمة التوضيحية
- `TRIPS` — الرحلات والأسعار والبرامج

## التشغيل
الموقع ملف واحد من غير أي مكتبات. افتح `index.html` في المتصفح، أو شغّله على GitHub Pages.
